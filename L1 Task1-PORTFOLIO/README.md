Personal Portfolio Website - Level 1 Task 1
This repository contains the source code for a responsive personal portfolio website developed as part of a web development internship task. The project focuses on creating a professional online presence using HTML and CSS.

📋 Project Overview
The goal of this task was to build a beginner-friendly web development project that includes essential sections to showcase an individual's skills, experience, and background.

✨ Features Implemented
Based on the task requirements, the following sections were developed:

Header Section: Includes the brand name "Karan Askand" with a navigation menu and a brief introduction/tagline.

About Section: Highlights a bio and professional focus areas, including a personalized image.

Experience & Education: A chronological timeline and grid layout detailing professional internships and academic history.

Skills Section: A categorized display of technical expertise in programming, AI/ML, and web tools.

Certifications & Projects: Showcase of real-world virtual internships (Tata, Deloitte) and hackathon participations.

Resume Section: Direct link to view the online resume or download the PDF version.

Contact Section: Integrated contact information (email, phone, location) and a functional link to a contact form.

Footer: A professional copyright notice and additional social links for navigation.

🛠️ Technologies Used
HTML5: For semantic structuring of the web content.

CSS3: For styling, layout (Flexbox/Grid), and responsive design.

Google Fonts: Specifically the 'Poppins' font family for modern typography.

JavaScript: Used for mobile menu toggling and UI interactions.
