Professional Portfolio Landing Page
This project is a responsive, modern personal portfolio landing page designed for a Computer Engineering student. It serves as a central hub to showcase professional experience, technical skills, certifications, and academic background.

## Features
Responsive Design: Fully compatible with mobile, tablet, and desktop views.

Dynamic Navigation: Smooth scrolling navigation bar with a mobile hamburger menu.

Hero Section: High-impact introduction with a typewriter effect and action buttons.

Experience & Education Timelines: Clean, organized sections using CSS cards and vertical timelines to display career progress.

Skills Grid: Categorized technical expertise (Programming, Data/AI, Tools).

Interactive Activity Gallery: Showcases extracurricular participation and leadership roles with image support.

Contact Integration: Integrated Google Forms for seamless user inquiries.

## Technical Implementation
The project utilizes fundamental web technologies to achieve a high-performance, user-friendly interface:

HTML5: Semantic structure for better SEO and accessibility.

CSS3: Custom properties (variables) for consistent branding, Flexbox/Grid for layout, and media queries for responsiveness.

JavaScript: Logic for the mobile menu toggle, "Back to Top" functionality, and smooth scroll behaviors.

Google Fonts: Utilizes 'Poppins' for a modern, clean typographic feel.
